# مواقيتي (الإصدار 1.1)

مواقيت الصلاة + القبلة + الأذكار + المسبحة + التقويم الهجري. يعمل بدون إنترنت.

## المميزات
- مواقيت فلكية بست طرق حساب، مع تعديل يدوي لكل صلاة بالدقائق وتعديل التاريخ الهجري.
- تنبيهات دقيقة لكل صلاة، تنبيه مسبق (5–30 دقيقة)، وتذكير بأذكار الصباح والمساء.
- **الأذان والمؤذنون:** اختيار المؤذن، أذان مستقل للفجر، تجربة الصوت قبل الاعتماد، وزر «إيقاف الأذان» في الإشعار.
- **إضافة أذان من ذاكرة الهاتف:** من الإعدادات ← إضافة أذان من الهاتف (mp3/ogg/wav/m4a، حتى 15 ميغابايت). يُنسخ الملف داخل التطبيق ولا يحتاج صلاحيات.
- ودجت للشاشة الرئيسية بالصلاة القادمة.
- القبلة ببوصلة، الأذكار (7 مجموعات بما فيها الأدعية)، مسبحة بستة أذكار.
- التقويم الهجري والمناسبات، متتبع الصلوات والسلسلة، جدول مواقيت الشهر، أسماء الله الحسنى.
- مشاركة مواقيت اليوم، سمة فاتحة/داكنة، حجم خط الأذكار.

## البناء عبر GitHub Actions
1. ارفع محتويات المجلد إلى مستودع جديد.
2. Actions ← Build APK ← Run workflow.
3. ستجد الـ APK في تبويب **Releases**.

## مؤذنون مدمجون داخل التطبيق (اختياري)
الملفات الصوتية غير مرفقة. إن أردت مؤذنين مدمجين، أنشئ المجلد `app/src/main/res/raw/` وضع فيه ملفات بهذه الأسماء (أي واحد أو أكثر) ثم أعد البناء، وسيظهر كل ملف موجود تلقائياً في قائمة المؤذنين:

`adhan_makkah` `adhan_madinah` `adhan_aqsa` `adhan_egypt` `adhan_fajr` `adhan_1` `adhan_2` `adhan_3`

(بصيغة mp3 أو ogg أو wav. تأكد أن لديك حق استخدام التسجيلات.)

## ملاحظات
- المواقيت تُحسب داخل الهاتف؛ طابقها مع تقويم الجهة الدينية في بلدك.
- التقويم الهجري حسابي (أم القرى) وقد يختلف يوماً عن الرؤية.
- راجع نصوص الأذكار والأدعية قبل النشر العام.
