# مواقيتي

مواقيت الصلاة + القبلة + الأذكار + المسبحة. يعمل بدون إنترنت.

## البناء عبر GitHub Actions
1. ارفع محتويات المجلد إلى مستودع جديد.
2. Actions ← Build APK ← Run workflow.
3. ستجد الـ APK في تبويب **Releases** (لا يستهلك حصة Artifacts).

## صوت الأذان (اختياري)
ضع ملفاً باسم `adhan.mp3` (أو ogg/wav) في `app/src/main/res/raw/` ثم أعد البناء.
ملاحظة: إن ثبّتّ التطبيق قبل إضافة الصوت فامسح بيانات التطبيق أو أعد تثبيته ليُنشأ التنبيه بالصوت الجديد.

## ملاحظات
- المواقيت تُحسب فلكياً داخل الهاتف؛ طابقها مع تقويم الجهة الدينية في بلدك.
- راجع نصوص الأذكار قبل النشر العام.
